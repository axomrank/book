## Chapter teaching format

Chapter 01 uses short concept explanations, tables of Assam sites and finds, dating comparisons, quick revision, eight original MCQs with explained answers, and one short-answer model. Six consolidated source notes retain citation support. The current HTML proof adds native 3D conceptual artwork and two faithful source image panels with raised mounts. It is an internal design proof, with reproduction clearance pending for the documentary figures.

HTML is the continuing editable master. Rebuild with `python production/html/render.py book/assam_history_series/01_prehistory_and_early_life/manuscript/01_Reading_the_Deep_Past.html output/pdf/Before_the_Kingdoms_Chapter_01_HTML_Design_Proof.pdf` from the repository root, using the pinned dependencies in `production/html/requirements.txt`. The earlier Markdown and ReportLab versions remain provenance snapshots.
