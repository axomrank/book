## Contents and status

`book/` contains every imported book plan, manuscript, research scan, extraction, page check, progress record and rendering script. `output/` contains the existing PDF proofs and cover exports; `tmp/pdfs/` preserves their visual review pages. The original cover-reference directory structure is preserved under `social assent/`.

`references/` adds the relevant downloaded historical object/document reproductions, monument photographs, dated GIS masters and four AI history concept illustrations with their records. These are research/design resources; inclusion is not historical validation or publication clearance. Modern administrative maps dated 2011/2021 must not be presented as medieval boundaries. AI images remain explicitly classified as illustrations.

Five chapters have first drafts (about 6,718 main-prose words). Sixteen Volume I chapter dossiers exist. The full work remains incomplete and is not publication-ready. Broader source comparison, historical review, chapter drafting, notes, bibliography, indexes, asset clearance and final layout remain necessary.

## Migration and rights

Historical provenance JSON retains old absolute machine paths. Use the relative links above for current navigation. The original PDF renderer also requires its recorded fonts and Python dependencies (ReportLab and pypdf); migration does not certify portable rendering.

[Media source/credit register](references/source-assets/media-register.json) accompanies the imported real media. Original rights registers are retained as clearly labelled snapshots, including records for assets not copied here; they are not a new book clearance decision. No blanket licence is assigned to this repository: sources, third-party media, AI artwork and original manuscript have distinct rights. Unverified legacy reference images remain research-only pending review.
